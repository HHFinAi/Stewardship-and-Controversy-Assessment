# Engagement objectives and leverage

Read `../../AGENTS.md` and `../../prompts/stages/engagement.md` relative to this skill directory. Obtain the current stage packet using the repository CLI. Do not create or claim unavailable source access.

## Task
Set measurable, time-bound objectives tied to a verified baseline, investor influence and mandate. Distinguish requests, commitments, implementation and independently supported outcomes. Disclose conflicts, escalation prerequisites and any constraints on collaboration.

## Deliverable
Return the fields in `../../schemas/artifact.schema.json`; use the current run ID and input digest. Required sections: baseline_and_target, milestones_owners_deadlines, leverage_and_collaboration, conflicts. Include source IDs, scope, periods, methods and material gaps. Call only allowlisted calculations with explicit provenance; missing evidence means NEEDS_DATA, not invented values.

## Limit
No automatic votes, emails, allegations of illegality, divestment, trading or claim of causal engagement success. Human approval is required before any external communication; this package has no sending or execution connection.
